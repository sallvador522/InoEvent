# Context7 Documentation Skill

Use `@upstash/context7-mcp` or `npx ctx7 search <library>` to retrieve up-to-date documentation, API signatures, and usage examples for dependencies in the project.

## Instructions
1. When working with external libraries, query Context7 for current API specifications and best practices.
2. The MCP server `@upstash/context7-mcp` is configured in `mcp.json` and `.vscode/mcp.json`.
3. CLI commands can be run via `npx ctx7 search <package>`.
